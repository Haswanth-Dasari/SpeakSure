# Archived Streamlit prototype

This directory preserves the pre-live-interview Streamlit prototype and its
tests for historical reference. It is not part of the current application,
runtime dependencies, or default pytest run.

The prototype requires Streamlit, which is intentionally not installed by
`requirements.txt`. To run it in a separate environment, install Streamlit
there and run `streamlit run legacy/app.py` from the repository root.
